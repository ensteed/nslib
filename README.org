* Noble Steed Libraries (nslib)
Collection of various libraries I've created and found useful over the years.

* Download
git clone https://github.com/dprandle/nslib.git
cd nslib
git submodule init
git submodule update

* Install Dependencies

** glslc and/or 
#+begin_src bash
sudo apt install glslc glslang-tools 
#+end_src

** SDL
#+begin_src bash
sudo apt update && sudo apt install -y \
  libwayland-dev \
  libx11-dev \
  libxkbcommon-dev \
  libegl1-mesa-dev \
  libgles2-mesa-dev \
  libdbus-1-dev \
  libibus-1.0-dev \
  libudev-dev
#+end_src

** Vulkan
For linux/mac/windows, download SDK and follow directions.

For RPI:
#+begin_src bash
sudo apt install libvulkan-dev vulkan-tools
#+end_src

* Build
mkdir build && cd build
cmake ..
make -j
